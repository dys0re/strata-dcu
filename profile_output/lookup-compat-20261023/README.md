# HC 修复与 prompt lookup 兼容

2026-10-23 的吞吐对照，2026-10-24 重启后接续功能检查。
SCNet gfx936、Qwen3.8-F AutoRound INT4、BS=1，全部 GPU 权重 ≤50%。
增强 MTP 固定 8500 个 GPU 专家；原生 DFlash2／联合模式固定 8300 个。
PLE 位于持久化磁盘。每类吞吐提示生成上限 256 tokens，预热后重复三次，
以引擎 DONE 的 decode_ms 计算实际输出速率，不含加载和 prefill。

## 改动

- HC 两个快速归一化函数仅在 DTK wave64 构建中限制隐式乘加合并。
  保留严格自检；split/staged 均已在完整引擎启动时通过逐位检查。
- 入口暴露缓存交换、锁页、PCIe 比例和搬运方式，见 [原生选项对照](../upstream-options-20261023/README.md)。
- suffix lookup 可与增强 MTP、原生 DFlash2、联合模式及 IPC 草稿结合。
  查找替代神经网络草稿时不更新被替代草稿的接受率，仍按目标模型实际提交的状态补齐缓存。
- 联合 lookup 窗口不混入旧 MTP 前缀；窗口限制于剩余上下文和输出长度。
  增强 MTP 的自身上限仍为 5 行，lookup 可以扩展到 7 行，总验证上限为 8。
- IPC 增加丢弃反馈命令，不清空上下文。

候选：`/root/private_data/strata-dcu/lookup-compat-20261023/strata`。
SHA256：`1c5b8a268585ab62bfe53a098c114b7e645c8befa91384d58c645fec9a8ff396`。
量化格式、CPU 线程池和专家槽数均未改变，也未恢复此前删除的预测调度器。

配置选择要求三项无超过 3% 的退步且几何平均提升超过 3%，并通过回答 QA；
这是本轮选择门槛，不是统计显著性结论。`code-function` 是代码 QA，
统计吞吐时只计入 `code-0/1/2`。`analyze.py` 分别记录运行成功与完整 QA 覆盖，
不会将 HC plain/split 的纯吞吐检查当作 14 项完整 QA。

## 已完成的验证

- 真实权重的 15 组草稿缓存检查：包含丢弃反馈后的重复、重置、增量和重算，
  eager/graph 输出一致；另有两个非法前缀拒绝检查。
- staged MTP、DFlash2、联合模式，以及各自 lookup 组合：14 项问答、算术、JSON、
  生成代码执行、多轮、采样和边界 QA，加取消恢复。
- lookup 组合额外检查重复文本原样复制和后续恢复。原生 DFlash2 的 24 个查找窗口
  对应 24 次反馈丢弃；其余原生组合也执行该计数一致性检查。
- 联合 lookup 的概率验证通过，实际执行 59 个概率验证窗口。
- 重启后原生 DFlash2 的长上下文检查通过：2100-token 提示后的 lookup 复制正确，
  恢复请求正常，10 个查找窗口对应 10 次反馈丢弃。

- 联合模式的 2100-token lookup 复制及恢复通过：7 个查找窗口、46/49 个候选被接受。
- 强制破坏每个联合候选后，16 个功能/lookup 请求与取消恢复通过；52 个查找窗口中
  71 个候选全部被拒绝，答案仍正确。
- IPC lookup 的 16 个请求及取消恢复通过，实际采用 16 个查找窗口。
- DMA smoke、三轮吞吐和完整 QA 通过，但速度退步，默认不启用。

生产入口已切换到 `strata-final`（与上述候选 SHA 相同）。最终公开入口独立复核已通过：增强 MTP、原生 DFlash2、联合模式各自的复制答案、lookup 使用、HC staged、权重账单和二进制 SHA 均正确，进程全部退出，GPU 回到 2 MiB。见 [独立验证记录](entry/validation.txt)。
